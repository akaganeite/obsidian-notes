# 内存管理模块，memory manager

## 对外接口

- 负责分配与回收内核对象资源

|      名称      |                           功能                           |
| :------------: | :------------------------------------------------------: |
| ut_alloc_frame |                    分配一页大小的内存                    |
|  ut_alloc_tcb  | 分配一个TCB(Task Control Block)大小的内存并返回Tcb结构体 |
|  ut_alloc_pt   |                         分配页表                         |
| ut_free_frame  |                     释放一页大小内存                     |
|  ut_free_tcb   |                    释放一个Tcb结构体                     |
|   ut_free_pt   |                         释放页表                         |
|                |                                                          |
|                |                                                          |
|                |                                                          |

## 用例

内核服务通过trusted_kernel_invoke!直接调用mm向外暴露的接口进行内核对象的申请与释放。申请内核对象返回该对象实例，申请方拥有该对象的所有权，直至显示调用mm暴露的资源释放接口，该接口拿走将先前申请的内核对象所有权并完成资源释放工作。
