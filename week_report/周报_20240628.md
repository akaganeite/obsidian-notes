## async/await

- 使用方法

```rust
goto(unit.clone(), 10).await;
//分解为goto函数调用，await调用
```

- goto函数：创建一个闭包，实现了poll函数,返回Future结构体，await相当于执行这个闭包。结构体包含闭包的一些信息`closure environment`(Vtable)

  ```rust
  fn goto(unit: Unit, target_pos: i32) -> impl Future<Output = ()> {
      GotoFuture::Start(unit, pos)
  }//仅调用goto函数，返回GotoFuture，编译器通过enum实现的一个状态机
  ```

  > The `goto` function just returns the `Future` object. Calling the `goto` function does not execute the async function. The async function is executed when the `Future` object is `await`ed.

- await：执行先前创建的闭包`goto::{{closure}}`,在闭包中内联了自己实现的poll函数。

  - 额外添加了一个状态机管理Future,每次executor调度到本闭包都会根据当前状态选择分支。
  - wake()函数属于executor范畴，它让executor第二次选择本Future时状态会被推进(具体实现逻辑需用户自己定义)
    - 实现为忙式等待，则不需要wake
    - 实现为类似事件驱动框架，需要wake函数通知事件到来


## executor

- 事件驱动方式：执行器会管理一批 `Future` (最外层的 `async` 函数)，然后通过不停地 `poll` 推动它们直到完成。 最开始，执行器会先 `poll` 一次 `Future` ，后面就不会主动去 `poll` 了，而是等待 `Future` 通过调用 `wake` 函数来通知它可以继续，它才会继续去 `poll` 。这种 **wake 通知然后 poll** 的方式会不断重复，直到 `Future` 完成。

- 忙式等待：执行器在自己的run/exec函数中忙式轮询所有的Future，每个循环将所有待完成的Future进行一次poll函数调用
