# 实际完成

## endpoint

- 使用方法

  - crate a/crate b拥有同一个endpoint(cspace中拥有指向同一个ep的cap)
  - a向ep注册callback，b使用send或者nb_send接口调用该callback，实现通信

- 暴露接口：nb_send&&send

  - nb_send为非阻塞调用，执行该函数不会立即执行callback，需要等到下一次线程调度或调用block函数显式等待结果

    ```rust
    //方法1:显示等待结果
    let return_hook = ep.nb_send(buf);
    //do otherthings
    let ret = return_hook.block();
    //方法2:无需等待结果，下一次线程调度时执行callback
    ep.nb_send(buf);
    return
    ```

  - send为阻塞调用，在send函数内部直接转去executor.nb_exec执行callback

- 内部实现：

  - 将channel中原先的链表结构替换为Segqueue，基于原子操作，可以实现无锁并发
  - 实现condvar，条件变量，绑定tcb，用于channel两端的wake和block操作

- 测试用例：

  - 单次send/nb_send
  - 嵌套send/nb_send:在callback中继续进行send操作
