# 实际完成

- 完善vfs功能
  - 增加系统打开文件表BTreeMap<id,inode>
  - 简化进程打开文件列表(fd_table),存储系统打开文件表中的对应id
- fs相关syscall支持：
  - read write open close lseek pread&pwrite pipe unlink dup&dup3
  - 可以实现打开读写关闭删除文件，创建管道以及io重定向
  - 所有syscall都遵循musl的调用规范(参数形式与syscall number)
- 实现ram-disk并对接至redoxfs，在初始化时将所有app的elf文件存入ram-disk。在每个execve时从ram-disk，通过fs加载elf文件
- 实现fs相关lmbench，测试读写与打开关闭开销。
- 缓解redoxfs栈开销
  - 重写BlockTrait，将其数据移动至堆
  - node，treedata等数据结构移动至堆
